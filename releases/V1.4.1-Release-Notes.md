# Invoice Maker V1.4.1

## Large supplier price-list performance

- Revalidates an entire confirmed import with a fixed number of database reads instead of querying once per item.
- Adds new items to Entity Framework in one batch while preserving the existing transaction and rollback behavior.
- Refreshes the Price List collection with one UI notification after import.
- Constrains and virtualizes the Price List grid so only visible rows are rendered.
- Keeps Price List fully separate from Store / Inventory.

This package retains all intelligent `.xlsx` and `.xls` supplier-import functionality introduced in v1.4.0. Existing database and license files in `%LOCALAPPDATA%\InvoiceSoftware` are not included in the application ZIP and remain unchanged.
