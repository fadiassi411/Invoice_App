# Invoice Maker v1.5.0

Price List entries can now be selected in both quotations and invoices.

- Search the independent Price List from the quotation Item Actions menu or the invoice item controls.
- Copy the selected item's reference, description, unit, price, and tax into a document line.
- Keep document values as snapshots, even if the Price List entry changes later.
- Leave Store / Inventory stock untouched when adding a Price List item.
- Reject currency mismatches without conversion; ask for confirmation when a Price List item has no currency.

The Windows download is a self-contained application. Extract the entire ZIP, then run `InvoiceSoftware.App.exe`. Existing data and license files under `%LOCALAPPDATA%\InvoiceSoftware` are not included in or replaced by the ZIP.
