# Invoice Maker v1.5.3

- Removed the duplicate **New Invoice** and **New Quotation** buttons from the upper-right header. The left-side **Quick Create** buttons remain available.
- In quotation PDFs, **Terms and conditions:** is now labeled and uses the same text styling and size as the other entries in **Commercial Terms**.

Existing invoices, quotations, database records, and license files are not changed by this update. The Windows x64 download is self-contained: extract the complete ZIP, keep its files together, then run `InvoiceSoftware.App.exe`.
