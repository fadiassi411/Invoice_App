# Invoice Maker V1.4.0

## Intelligent supplier Excel importing

- Imports supplier `.xlsx` and `.xls` price lists without modifying the source file.
- Detects sheets and header rows below titles, logos, merged cells, and blank rows.
- Maps item number, description/name, price, currency, category, brand, unit, and tax fields by common header names.
- Requires confirmation when mappings are incomplete, uncertain, or contain multiple price choices.
- Preserves item identifiers and formatted leading zeros, price precision, descriptions, and currencies.
- Previews creates, updates, warnings, errors, and skipped rows before any database write.
- Reports each issue with source sheet, Excel row, original value, and explanation.
- Uses one database transaction so a failed import cannot leave partial changes.
- Remembers confirmed header mappings and parsing settings per supplier and revalidates them on every file.
- Allows supplier mappings to be edited or reset.

## Data safety

Price List remains fully separate from Store / Inventory. Supplier imports never create inventory products or change quantities, costs, invoices, or quotations. Existing database and license data remain in `%LOCALAPPDATA%\InvoiceSoftware` and are not included in the application ZIP.
