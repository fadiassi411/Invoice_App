# Invoice Maker v1.5.1

The Price List page now has a cleaner, grouped action bar.

- Use **Item** for New Item, Save Item, and Delete Selected Item.
- Use **Excel** for supplier import and catalogue export, and **View** to refresh.
- Select a supplier, then use **Supplier actions** to delete only that supplier's list after confirmation.
- Use each row's **Item actions** menu to delete that row, or **Image actions** in the editor to choose or remove its image.

This update changes the interface only. The Price List remains separate from Store / Inventory, and existing application data and license files are not included in or replaced by the ZIP.

Download the Windows x64 ZIP from this release's **Assets**. Extract the entire ZIP, keep all files together, then run `InvoiceSoftware.App.exe`.
