# Invoice Maker V1.3.0

## New: Price List

- Dedicated **Price List** page with its own independent catalogue records.
- Price-list edits and Excel imports do not create or modify Store / Inventory products.
- Export active catalogue items to a formatted Excel `.xlsx` workbook.
- Import price-list workbooks by reference number, updating existing items or creating new ones.
- Optional item image selection with safe local application storage.
- Excel exports include available item images and all customer-facing price-list fields.

## Data compatibility

V1.3.0 adds a separate `PriceListItems` table. The application applies the migration automatically on first start. Existing invoices, quotations, products, inventory costs, and quantities are unchanged.
