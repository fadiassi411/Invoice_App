# Invoice Maker v1.5.2

The Quotations list now has a clearer layout and grouped action menus.

- Search filters have visible labels; press Enter in the search box or choose **List → Search Quotations** to apply them.
- Use **List** to search or export CSV.
- Use **Quotation** to create, open, duplicate, or revise a quotation.
- Select a row, then use **Workflow** to convert, archive, or permanently delete it. Existing confirmation and deletion safeguards remain in place.

This is an interface update. Quotation, invoice, inventory, database, and licensing behavior is unchanged. Existing application data and license files under `%LOCALAPPDATA%\InvoiceSoftware` are not included in or replaced by the ZIP.

Download the Windows x64 ZIP from this release's **Assets**. Extract the entire ZIP, keep all files together, then run `InvoiceSoftware.App.exe`.
