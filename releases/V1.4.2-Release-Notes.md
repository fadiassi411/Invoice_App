# Invoice Maker v1.4.2

## Price List deletion controls

- Delete an individual item with the button on its row or **Delete Selected Item** at the top of the page.
- Select a supplier and choose **Delete Supplier List** to remove every active Price List entry belonging to that supplier. The confirmation displays the supplier name and item count.
- Other suppliers' entries and manually created items remain available.
- Deletion uses the app's existing soft-delete behavior. Store / Inventory data is not changed.

The Windows ZIP contains the app and supporting files. The existing database and license under `%LOCALAPPDATA%\InvoiceSoftware` are not included.
